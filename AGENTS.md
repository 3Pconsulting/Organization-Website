# Working in this repo

This repo is **public** and is served live on 3phelpme.com. Anything committed here can be read by anyone.

- **Internal documents, standards, notes, analytics and agent instructions live in the private repo `3Pconsulting/3p-operations`.** Start with `docs/1-manual/3P-MAN-001-start-here.md` there.
- Never commit internal documents, notes, analytics, local file paths, keys or credentials to this repo.
- Commits made by an AI agent include a `Co-Authored-By:` trailer.
